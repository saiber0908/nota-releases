# Nota

Установщики и обновления Nota для Windows — учёба и языки с ИИ. Исходного кода здесь нет, только релизы.

**Скачать:** [последний релиз](https://github.com/saiber0908/nota-releases/releases/latest) → `Nota_<версия>_x64-setup.exe`.

- Устанавливается без прав администратора, в папку пользователя.
- Обновления Nota находит сама и ставит, когда нажмёшь «Перезапустить». Каждое обновление подписано: чужой файл приложение не установит.
- Пока установщик не подписан сертификатом издателя, Windows может показать окно SmartScreen. Нажми «Подробнее» → «Выполнить в любом случае».
