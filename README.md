# Nota

Установщики и обновления Nota для Windows — учёба и языки с ИИ. Исходного кода здесь нет, только релизы.

**Скачать:** [последний релиз](https://github.com/saiber0908/nota-releases/releases/latest) → `Nota-Setup-<версия>.exe`.

- Ставится без прав администратора, в папку пользователя, за несколько секунд. Если Nota уже стоит, установщик предложит обновить её или просто открыть.
- Обновления Nota находит сама и ставит, когда нажмёшь «Перезапустить». Каждое обновление подписано и привязано к своей версии: чужой файл приложение не установит.
- Пока установщик не подписан сертификатом издателя, Windows может показать окно SmartScreen. Нажми «Подробнее» → «Выполнить в любом случае».
- Удалить — как любую программу: «Параметры» → «Приложения». Данные (материалы, разговоры, карточки) удаляются, только если поставить галочку.
